# CyberCloud 雲端神搜特工隊 🚀
> **國中 108 課綱資訊科技互動闖關學習網**  
> 專為南一版國中資訊科技 1上「第二章 2-1 雲端運算服務與網路資料搜尋技巧」量身打造的沉浸式生活實例測驗系統。

---

## 🌟 系統特色

1. **生活與學習案例為主幹**：
   - 告別枯燥死背！全題庫 30 題皆源自國中生真實情境（分組報告分頁手滑誤關、以圖搜圖找校園生物、用 `site:edu.tw` 與 `filetype:pdf` 抓官方會考考古題、雲端共編手滑救援時光機、避免釣魚廣告與公開連結資安守門員）。
2. **三階段漸進式特工闖關（共 30 題）**：
   - 🎯 **第一關：【基底整備】雲端與瀏覽器實戰特訓（10題）**：Chrome 快捷鍵（Ctrl+Shift+T、Ctrl+D、Ctrl+Shift+N、/）、雲端運算虛擬化概念、Google 辦公四寶（文件/試算表/簡報/表單）生活配對、資料備份（上傳/下載）。
   - 🎯 **第二關：【雷達開展】搜尋初階偵探挑戰（10題）**：關鍵字去蕪存菁、空格（AND 交集）、減號（- 排除）、連續數值（.. 範圍）、搜尋工具時間篩選、Google Lens 以圖搜圖、行銷廣告與贊助商辨識、燙傷急救生活查證。
   - 🎯 **第三關：【神搜奧義】進階指令與雲端共創密碼（10題）**：雙引號（"" 完全吻合）、`filetype:`（指定 PPTX/PDF）、`site:`（指定 edu.tw / gov.tw）、複合指令實戰、雲端硬碟三大權限（檢視者/加註者/編輯者）、資料夾權限繼承、版本歷史紀錄救援、共用人數上限。
3. **能力驗證導向題型**：
   - **智慧克漏字填空 (Cloze Fill-in)**：自動容錯全半形符號、大小寫與多餘空格。
   - **Google 極速搜尋模擬器 (Search Simulator)**：學生親自於搜尋列鍵入指令，即時回饋模擬過濾結果。
4. **遊戲化激勵回饋**：
   - 生命值 (HP)、特工經驗值 (XP)、連擊 Combo 機制。
   - Web Audio API 原生無延遲合成音效（答對和弦、答錯震鈴、通關號角）。
   - 特工錦囊提示系統（卡關不氣餒）。
5. **通關證書生成系統**：
   - 全域通關後，系統利用 HTML5 Canvas 即時動態生成個人化「**國中資訊科技 雲端運算與網路神搜特工 合格證書**」，印有學生姓名、班級、得分解鎖等級與數位防偽印章，支援 **一鍵下載高畫質 PNG 圖片** 或 **列印存成 PDF** 交給老師！

## 🌐 如何發布公布在網站（3種推薦發布方式）

本系統為純原生前端設計（HTML5 / CSS3 / Vanilla JS），無任何後端依賴與伺服器資料庫負擔，支援永久免費發布於各大靜態網站託管平台：

### 方案 A：使用 GitHub Pages（完全免費、適合班級長期使用）
1. 將本專案資料夾的所有檔案推送（Push）到您的 GitHub Repository（儲存庫）。
2. 在 GitHub 儲存庫頁面點擊 **Settings** ➜ 進入左側的 **Pages**。
3. 在 **Build and deployment** 來源選擇 **Deploy from a branch**，分支選擇 `main`（或 `master`），資料夾選擇 `/ (root)`，點擊 **Save**。
4. 稍等約 1 分鐘，即可獲得公開發布的網址（例如：`https://<你的帳號>.github.io/<專案名稱>/`），可直接提供給學生與家長在手機、平板或電腦上闖關！

### 方案 B：使用 Vercel 或 Netlify（一鍵拖曳上線）
1. 前往 [Netlify Drop](https://app.netlify.com/drop) 或 [Vercel](https://vercel.com/)。
2. 直接將本資料夾拖曳進網頁中，約 10 秒內即可自動獲得一組專屬 HTTPS 網址！

### 方案 C：學校區域網路或本機電腦教室使用
1. 直接在 Windows 電腦中雙擊 `index.html` 即可在 Chrome / Edge 中離線遊玩。
2. 或者雙擊專案目錄下的 `start_server.bat`，即可在本機以 HTTP 伺服器方式運行，並可在同區域網路下分享給整間電腦教室的學生連線測驗！
