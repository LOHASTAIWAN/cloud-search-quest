## 🌟 核心新功能與特色

### 1. 學生身分檢核閘口（匯入 115 級 318 位名條）
- 學生每次測驗前，必須輸入本人的**班級、座號、姓名與 7 碼學號**。
- 系統內部即時校驗 `students.json`（由 `1151103中一班級名條 (7).xlsx` 正式匯出），四項欄位完全一致才放行進入大廳，嚴防冒名或誤填。
- 每次登入精確記錄「身分認證登入時間戳記」，並同步至後台資料庫。

### 2. 八大單元生活實戰題庫（共 80 題）
- 🎯 **單元 1-1：【基底整備】雲端與瀏覽器實戰特訓（10題）**：Chrome 快捷鍵（Ctrl+Shift+T、Ctrl+D、Ctrl+Shift+N、/）、雲端虛擬化、Google 四寶生活配對、資料備份（上傳/下載）。
- 🎯 **單元 1-2：【雷達開展】搜尋初階偵探挑戰（10題）**：去蕪存菁關鍵字、空格（AND）、減號（- 排除）、數值範圍（..）、工具時間篩選、Google Lens 以圖搜圖、廣告辨別。
- 🎯 **單元 1-3：【神搜奧義】進階指令與雲端共創密碼（10題）**：雙引號（"" 完全吻合）、`filetype:`、`site:`、複合指令實戰、雲端硬碟三大權限（檢視者/加註者/編輯者）、版本歷史紀錄還原。
- 🎯 **專題 2-1：【思維藍圖】低碳生活心智圖（Google 文件）（10題）**：心智圖發想核心、文字排版字級加粗、段落行距、頁首/頁尾、文字環繞圖片、繪圖工具嵌入、大綱導覽。
- 🎯 **專題 2-2：【數據魔術】食物碳排放量估算表（Google 試算表）（10題）**：儲存格座標（欄與列）、等號公式開頭、五大必學函數（`SUM`、`AVERAGE`、`MAX`、`MIN`、`COUNT`）、自動填滿控點、碳足跡定義、遞減排序。
- 🎯 **專題 2-3：【視覺傳播】友善地球簡報（Google 簡報）（10題）**：文字條列精簡、黑底白字高對比、色彩三原則、版面配置雙欄切換、頁面轉場、圖表連動嵌入、四角等比例縮放、演講者備忘稿。
- 🎯 **專題 2-4：【民意雷達】低碳意識調查表（Google 表單）（10題）**：資料收集目的（佐證假設）、圓形單選題、方形核取方塊、1~5 分線性刻度、長篇段落題、必填設定、問卷分區段、傳送縮短網址、回覆統計圖表。
- 🎯 **專題 2-5：【洞察未來】資訊小達人（資料分析與資訊素養）（10題）**：資料（原石）vs 資訊（有價成果）核心分野、圓餅圖（比例）vs 長條圖（數量）、表單連動試算表、漏斗資料篩選（Filter）、條件式格式變色警報、隱私去識別化保護、創用 CC 授權、數位足跡責任。

### 3. 教師後台監控中心 (Teacher Admin Dashboard)
- 點選右上角「**🔐 教師後台**」，輸入密碼 `teacher115` 即可進入：
  - 📊 **每題通過率分析牆**：即時統計 80 道題目的作答次數與通過率百分比，自動標註「⚠️ 迷思概念 / 易錯難題」，幫助老師掌握教學盲點。
  - 📋 **學生登入日誌與成績冊**：可依 11 個班級篩選，檢視全體 318 位學生登入時間、各單元平均得分與通過狀態。
  - 📥 **一鍵匯出 Excel (CSV) 成績冊**：帶有 UTF-8 BOM，Excel 直接點開不亂碼，期末算成績超省力！

### 4. Cloudflare 雲端後台支援
- 專案包含 `worker.js` 與 `wrangler.toml`，提供正式 REST API：
  - `POST /api/auth/login`：學生登入日誌登記
  - `POST /api/scores/submit`：各單元分數與每題對錯狀態回傳，即時計算通過率
  - `GET /api/admin/overview`：教師後台數據總覽
  - `GET /api/admin/export-csv`：遠端 CSV 匯出
- **雙軌架構**：學生在瀏覽器本地會自動快取持久化，同時只要在後台設定您的 Cloudflare Worker 網址，即可雙向雲端同步！

## 🚀 如何部署至個人的 Cloudflare？

1. **部署後端 Worker**：
   - 雙擊專案目錄下的 `deploy_cloudflare.bat`。
   - 瀏覽器將自動彈出 Cloudflare 登入授權，完成後終端將自動部署 `worker.js`，並產出一組專屬網址（例如：`https://cybercloud-backend.<你的帳號>.workers.dev`）。
2. **在網頁後台綁定**：
   - 開啟網頁，點選右上角「教師後台」➜「Cloudflare 串接設定」➜ 貼上該網址並儲存即可！
